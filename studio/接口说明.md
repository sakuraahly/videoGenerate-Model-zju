# 接口说明（形态①：创空间 Agent + 外部 API）

> 定案（2026-09-10 用户选定）：**创空间只放 Agent（决策+前端），不部署模型**，通过外部 API 生成。
> 本文件=**留好的接口清单**：把下面环境变量填进空间「设置 → 变量 / 密钥」即可真实出片；不填就是规划演示。

## 一、环境变量一览（填在空间里，代码不存任何密钥）

| 变量 | 必填 | 用途 | 示例 |
|---|---|---|---|
| `LLM_BASE_URL` | 可选 | 决策模型地址（OpenAI 兼容） | `https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `LLM_API_KEY` | 可选 | 决策模型密钥（**放密钥区**） | `sk-…` |
| `LLM_MODEL` | 可选 | 模型名 | `deepseek-chat`、`qwen-plus` |
| `VIDEO_API_URL` | **要出片则必填** | 外部视频生成服务 | `https://your-engine.example.com/v1/jobs` |
| `VIDEO_API_KEY` | 视服务 | 视频服务密钥（**放密钥区**） | `Bearer …` |
| `VIDEO_API_STATUS_URL` | 可选 | 异步作业查询（不填=同步直返） | `https://your-engine.example.com/v1/jobs` |

> 不填任何变量 → 空间进入**规划演示**（照样展示 Agent 的决策轨迹与匹配样片，比赛演示不断档）。

## 二、视频生成接口协议（二选一）

### 协议 A：异步作业（推荐，适合长任务）
```
POST {VIDEO_API_URL}
Authorization: Bearer {VIDEO_API_KEY}
Content-Type: application/json

{ "kind": "t2v|talk|story",     // 任务类型：文生视频 / 说话镜头 / 故事片
  "prompt": "…",                 // 创意或提示词
  "text": "台词原文",             // kind=talk 时
  "voice": "h3|yunxi|xiaoxiao|aria|daler",
  "resolution": "480p",
  "seconds": 5 }

→ 200 { "job_id": "abc123" }

GET {VIDEO_API_STATUS_URL}/{job_id}
Authorization: Bearer {VIDEO_API_KEY}

→ 200 { "status": "queued|running|completed|failed",
        "video_url": "https://…/result.mp4",   // completed 时
        "error": "…" }                          // failed 时
```
空间侧会每 10 秒轮询一次，最长约 10 分钟；拿到 `video_url` 就在页面上播放。

### 协议 B：同步直返（适合秒级服务）
```
POST {VIDEO_API_URL}   同一请求体
→ 200 { "video_url": "https://…/result.mp4" }
```
（不配置 `VIDEO_API_STATUS_URL` 时按本协议处理。）

## 三、决策模型接口（可选）
标准 OpenAI 兼容 `POST {LLM_BASE_URL}/chat/completions`（`messages` + `response_format=json_object`）。
空间把 4 个工具的能力与参数写进 system 提示，模型返回：
```json
{ "tool": "generate_talk", "args": { "text": "天冷了，快进屋坐坐吧。", "voice": "h3" }, "say": "给用户的一句说明" }
```
不配 LLM 时，内置**规则规划器**产出同样结构（关键词→工具），保证演示可用。

## 四、工具（Agent 可自主选择）
| 工具 | 用途 | 关键参数 |
|---|---|---|
| `generate_video` | 文生视频（有参考图则图生视频） | prompt, resolution, seconds, image |
| `generate_talk` | **说话镜头**：人物亲口说出台词（音色/时长自动匹配） | text, image, voice |
| `make_story_film` | 剧本→多段连贯故事片（含台词字幕） | script, segments |
| `answer` | 答疑/建议（不生成） | text |

## 五、怎么自测
1. 什么都不填 → 打开空间，进「🤖 Agent 对话」，点三个示例按钮：能看到**工具选择 + 参数 + 轨迹**（规划演示）。
2. 填 `VIDEO_API_URL`（+ `VIDEO_API_KEY`）→ 再发同样的话，会真实调用并在页面出片。
3. 填 `LLM_*` → 决策由大模型完成（能用自然语言理解复杂需求，比如"让老人用沧桑的声音说一句…，不要字幕"）。
