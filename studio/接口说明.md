# 接口说明（创空间交付件：Agent = 工具集 + 外置大脑）

> **对齐《ModelScope-Agent 学习指南》（2026-09-10）**：平台的标准形态是「零代码/低代码创建 Agent → 发布 → 只取
> `AGENT_URL` → 在创空间里替换这个环境变量 → 重启空间展示」。因此本空间把 **`AGENT_URL` 作为首选大脑通道**：
> 平台上的 Agent（自带 prompt / tools / 知识）负责决策，本空间负责「工具集 + 前端 + 预览/下载」。
> 代码级魔改则改 `config/builder_config.json`（见 `studio/builder_config.example.json`）再 push。
> 优先级：**`AGENT_URL` > `LLM_*` > 内置规则规划器**；都不配 = 规划演示（照样展示决策与请求体预览，不空转、不崩）。

> 定案（2026-09-10）：**创空间只放 Agent，不部署模型**；Agent 由两半组成——
> ①**工具集**（下面第四节的 4 个工具，全部走 HTTP，空间内零本机依赖）；
> ②**外置大脑**（`LLM_*` 接口控制的模型，决定"用哪个工具、什么参数"）。
> 出片统一走**预留的视频生成模型接口**（`ENGINE_*`）。不填变量 = 规划演示（照样展示决策与请求体预览），不空转、不崩。

## 一、环境变量一览（填在空间「设置 → 变量 / 密钥」，代码不存任何密钥）

| 变量 | 必填 | 用途 | 示例 |
|---|---|---|---|
| `AGENT_URL` | 可选（**平台首选**） | 魔搭平台上「构建-发布」得到的 Agent 地址；本空间把用户消息转给它决策 | `https://xxx.modelscope.cn/api/v1/agent/xxx` |
| `AGENT_TOKEN` | 视平台 | 调用该 Agent 的令牌（**放密钥区**） | `Bearer …` |
| `ENGINE_BASE_URL` | **要出片则必填** | 视频生成模型接口地址 | `https://your-engine.example.com/v1/jobs` |
| `ENGINE_API_KEY` | 视服务 | 接口密钥（**放密钥区**） | `sk-…` |
| `ENGINE_STATUS_URL` | 可选 | 异步作业查询地址（不填=同步直返） | `https://your-engine.example.com/v1/jobs` |
| `LLM_BASE_URL` | 可选 | **外置大脑**地址（OpenAI 兼容） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `LLM_API_KEY` | 可选 | 大脑密钥（**放密钥区**） | `sk-…` |
| `LLM_MODEL` | 可选 | 大脑模型名 | `qwen-plus` / `deepseek-chat` |
| `TOOLSET` | 可选 | 开放给大脑的工具子集 | `generate_talk,answer`（默认 all） |
| `AGENT_SYSTEM_PROMPT` / `AGENT_SYSTEM_PROMPT_FILE` | 可选 | 外置 system 提示：注入行业规则/铁律 | `必须中文回答；台词照抄不改写` |

> 旧名 `VIDEO_API_URL` / `VIDEO_API_KEY` / `VIDEO_API_STATUS_URL` **仍然兼容**（新名优先）。
> 一个都不填 → **规划演示**：Agent 正常选工具、给参数，并把"即将发给接口的请求体"原样打印在页面上。

## 二、视频生成接口协议（二选一）

### 协议 A：异步作业（推荐，适合长任务）
```
POST {ENGINE_BASE_URL}
Authorization: Bearer {ENGINE_API_KEY}
Content-Type: application/json

{ "kind": "t2v|i2v|talk|story",   // 文生视频 / 图生视频 / 说话镜头 / 故事片
  "prompt": "…",                  // kind=t2v/i2v：创意或提示词
  "image_b64": "data:image/png;base64,…",   // 可选：参考图（i2v/talk 建议带）
  "text": "台词原文",              // kind=talk：要人物说出的话（照抄，不许改写）
  "voice": "native",              // kind=talk：native=模型原生音色（推荐）；也可指定音色名
  "script": "…", "segments": 3,   // kind=story：剧本与段数
  "resolution": "480p",
  "seconds": 5 }

→ 200 { "job_id": "abc123" }

GET {ENGINE_STATUS_URL}/{job_id}
Authorization: Bearer {ENGINE_API_KEY}

→ 200 { "status": "queued|running|completed|failed",
        "video_url": "https://…/result.mp4",   // completed 时
        "error": "…" }                          // failed 时
```
空间侧每 10 秒轮询一次（最长约 10 分钟）；拿到 `video_url` 后**自动取回空间本地**再内嵌播放（见第五节）。

### 协议 B：同步直返（适合秒级服务）
```
POST {ENGINE_BASE_URL}   同一请求体
→ 200 { "video_url": "https://…/result.mp4" }
```
（不配置 `ENGINE_STATUS_URL` 时按本协议处理。）

## 二·五、平台 Agent 通道（`AGENT_URL`，首选）

调用方式对返回形态**容错**，以下三种都能接（按顺序尝试，任一种成功即用）：

| 形态 | 请求 | 取值路径 |
|---|---|---|
| A｜OpenAI 兼容 | `POST {AGENT_URL}` `{"model":"...","messages":[…],"stream":false}` | `choices[0].message.content` |
| B｜通用 JSON | `POST {AGENT_URL}` `{"messages":[…]}`／`{"input":"…","messages":[…]}` | `data.text` / `response` / `answer` / `content` / `text` / `output_text` … |
| C｜SSE 流 | 同上，`Accept: text/event-stream` | 逐行拼 `data:` 分片，遇到 `[DONE]` 停 |

- 鉴权：配置了 `AGENT_TOKEN` 就带 `Authorization: Bearer …`；
- **两种用法都支持**：①平台 Agent 按我们的约定回 `{"tool":…,"args":…,"say":…}` → 直接执行工具；
  ②平台 Agent 只回自然语言 → 当成 `answer` 交付（**不硬套工具、不假装出片**）；
- 调用失败 → 明确回一句「平台 Agent 暂不可用…本轮按内置规则执行」，并降级到 `LLM_*` / 规则规划器；
- 页面顶部会显示**当前大脑通道**：`平台 Agent（AGENT_URL）` / `自建大脑（LLM_*）` / `内置规则规划器`。

## 三、外置大脑接口（可选）
标准 OpenAI 兼容 `POST {LLM_BASE_URL}/chat/completions`，空间发送：
- `messages[0]` = **system 提示**：默认铁律 + `TOOLSET` 允许的工具与其参数 JSON（可用 `AGENT_SYSTEM_PROMPT*` 覆盖默认提示）；
- 最近 6 轮对话 + 本轮用户输入；
- `response_format={"type":"json_object"}`。

模型需返回（只返回这一个 JSON）：
```json
{ "tool": "generate_talk", "args": { "text": "天冷了，快进屋坐坐吧。", "voice": "native" }, "say": "给用户的一句说明" }
```
空间拿到后校验：工具必须在 `TOOLSET` 内，参数经 `build_payload()` 翻译成第二节的请求体再执行。
大脑不可用或未配置时，内置**规则规划器**产出同样结构的计划——演示不断档，且轨迹区会标明当前模式。

## 四、工具（Agent 的手脚，可自主选择）
| 工具 | 用途 | 关键参数 | 落到接口的 kind |
|---|---|---|---|
| `generate_video` | 文生视频；带参考图则图生视频 | prompt, resolution, seconds, image_b64 | `t2v` / `i2v` |
| `generate_talk` | **说话镜头**：人物亲口说出台词（音色/时长由模型侧匹配） | text, image_b64, voice | `talk` |
| `make_story_film` | 剧本 → 多段连贯故事片 | script, segments | `story` |
| `answer` | 答疑/建议（不生成） | text | 不出网 |

## 五、空间内等价实现的"本机功能"
原来跑在本机 GPU 机器上的这些能力，在空间里用**接口 + 页面**等价实现，不依赖任何本机环境：

| 本机能力 | 空间内实现 |
|---|---|
| 参考图预览/选图 | 页面上传图片 → Gradio 即时预览 → 自动转 `data URL`（`image_b64`）注入工具参数 |
| 任务提交与排队 | 工具一次 HTTP 调用（`POST ENGINE_BASE_URL`）→ 返回 `job_id` |
| 进度查看 | **任务面板**（本会话任务表：时间/任务号/工具/状态/成片），"🔄 刷新任务状态"主动查询 |
| 结果预览与下载 | 拿到 `video_url` 后自动**取回空间本地**（`studio/outputs/`，保留最近 12 个）再内嵌播放；同时给出原链接 |
| 决策过程可见 | 轨迹区展示工具、参数、请求体、响应与轮询序列（base64 自动省略，避免日志膨胀） |
| 字幕/拼接/口型 | 由外部视频模型接口在 `kind=talk` / `kind=story` 内完成（空间侧**不做转码**，免费 CPU 不浪费在重编码上） |

## 六、怎么自测
1. **不填任何变量**：进「🤖 Agent 对话」点示例 → 看到"工具 + 参数 + 请求体预览"（规划演示）。
2. **只填 `ENGINE_*`**：同样的话 → 真实提交、轮询、出片、任务面板出现记录。
3. **再填 `LLM_*`**：决策交给大模型（能理解"用沧桑的声音说一句…，不要字幕"这类复合要求）。
4. **仓库自带假引擎自测**（不花钱、不联网也可跑）：
   ```bash
   py -3 tests/mock_engine.py --port 7999 --video studio/assets/01_direct_720p.mp4
   # 另开一个终端/进程，设置 ENGINE_BASE_URL=http://127.0.0.1:7999/v1/jobs 后启动 studio/app.py
   ```
   假引擎同时提供 `/v1/llm/chat/completions`（假大脑）与 `/v1/llm/stats`（回看空间发过去的 system 提示与工具清单）。
