# 快速上手（下载后本地跑，填两个 key 即可）

> 目标：把本项目下载到本地，**填一个大模型 key + 一个视频生成接口**，就能真实出片。
> 全程 5 分钟；不填 key 也能跑（进入「规划演示」，只展示决策与请求体，不联网）。

## 一、准备

- Python 3.10+（3.11/3.12 都可以）
- 一个大模型 key（通用模型，OpenAI 兼容）：阿里云百炼 / DeepSeek / 魔搭 / 智谱 任选
- 一个视频生成接口（可以是：你自己的 GPU 网关、或任何实现了下面两个动作的服务）

## 二、三条命令

```bash
git clone https://github.com/sakuraahly/videoGenerate-Model-zju.git
cd videoGenerate-Model-zju/studio
pip install -r requirements.txt        # 只有 gradio/pyyaml，平台镜像已内置
python app.py --port 7860               # 浏览器打开 http://127.0.0.1:7860
```

## 三、填 key（两种方式，选一种）

### 方式 A：页面上填（最快，不用重启）

打开页面 → 展开「🔑 我的密钥」→
1. **① 选服务商**（百炼/DeepSeek/魔搭/智谱/自定义）→ 地址与模型名自动填好；
2. **③ 贴 API Key**；
3. 展开「（可选）视频生成接口」填 `ENGINE_BASE_URL` / `ENGINE_STATUS_URL` / `ENGINE_API_KEY`；
4. 点 **🔌 测试外置大脑连接** → 看到 `✅ 大脑可用…ms` 即通；
5. 回对话区说一句需求，例如：「让参考图里的老人说一句『天冷了，快进屋坐坐吧』」。

### 方式 B：写一个 `.env`（适合想固化配置的人）

在 `studio/` 目录下新建 `.env`：

```ini
# 通用大模型（示例：阿里云百炼）
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen-plus
LLM_API_KEY=sk-你的百炼key

# 视频生成接口（两个动作，见下）
ENGINE_BASE_URL=http://127.0.0.1:9000/v1/jobs
ENGINE_STATUS_URL=http://127.0.0.1:9000/v1/jobs/status
ENGINE_API_KEY=你的引擎token
```

程序启动时会**自动读取** `studio/.env`（已加进 `.gitignore`，不会被提交）。
也兼容更早的变量名：`VIDEO_API_URL` / `VIDEO_API_KEY` / `REMOTE_API` + `STUDIO_TOKEN`（自动映射）。

## 四、视频生成接口只要两个动作

| 动作 | 请求 | 返回 |
|---|---|---|
| 提交 | `POST {ENGINE_BASE_URL}`，body 见下 | `{"job_id": "abc123"}` |
| 查询 | `GET {ENGINE_STATUS_URL}/{job_id}` | `{"status":"running|completed|failed", "video_url":"..."}` |

提交 body（Agent 自动拼）：

```json
{"kind":"talk","text":"天冷了","voice":"native","resolution":"480p"}
{"kind":"t2v","prompt":"a cat by the window, warm light","resolution":"480p","seconds":5}
{"kind":"i2v","prompt":"…","image_b64":"data:image/png;base64,…","resolution":"480p","seconds":5}
{"kind":"story","script":"…","segments":3,"resolution":"480p","seconds":5}
```

## 五、没有现成视频接口？先自测整条链

仓库自带**假引擎**：`tests/mock_engine.py`（起一个进程即扮演引擎 + 大脑），
用它可以把「Agent → 请求体 → 轮询 → 取回成片 → 页面预览」跑通而不花钱；换成真服务只需改 `.env` 里的地址。

## 六、自检

```bash
python agent_client.py --status      # 当前配置、模式、自检告警
python agent_client.py --selftest    # 真实调用一次你的大模型（只发一条极小请求，不触发出片）
```

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 页面显示「规划演示」 | 正常：还没配 `ENGINE_*`（或页面上没填），只预览请求体 |
| 自测报 401 | key 错 / 额度用尽 / 模型名不对 |
| 提交后一直没结果 | 引擎侧没实现查询接口，或状态字段名不对（需 `status` + `video_url`） |
| 想换模型 | 页面「我的密钥」选「自定义」，或改 `.env` 的 `LLM_*` |
| 端口被占用 | `python app.py --port 7861` |
