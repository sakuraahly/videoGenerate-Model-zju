# H3 视频生成工坊 · 魔搭创空间（Agent v2.4）

> **v2.4（2026-09-10）交付形态定案：空间里放的就是一个完整的 Agent = 工具集 + 外置大脑。**
> ① **工具集**（Agent 的手脚，全部 HTTP，空间内零本机依赖）：`generate_video` / `generate_talk` / `make_story_film` / `answer`，
> 可用 `TOOLSET` 收窄开放范围；
> ② **外置大脑**（决策，`LLM_BASE_URL`/`LLM_API_KEY`/`LLM_MODEL` 接口控制）：system 提示与工具 schema 一起送进模型，
> 模型只回一个 `{tool,args,say}`；提示本身可外置注入（`AGENT_SYSTEM_PROMPT` / `AGENT_SYSTEM_PROMPT_FILE`）；
> ③ **出片走预留的视频生成模型接口**：`ENGINE_BASE_URL` / `ENGINE_API_KEY` / `ENGINE_STATUS_URL`（旧名 `VIDEO_API_*` 兼容）；
> ④ **本机功能在空间内等价实现**：参考图上传即时预览（转 `image_b64` 入参）、请求体预览（演示模式）、
> 任务面板（时间/任务号/工具/状态/成片 + 一键刷新）、成片取回 `studio/outputs/` 后内嵌播放 + 原链接下载、决策轨迹可见。
> 本空间**不含任何某台本机的适配代码**：换机器/换模型服务只改环境变量。接口契约见 `studio/接口说明.md`。

> **v2.0（2026-09-10）前端重构**：从"展示页"升级为**专业创作台**——
> **Tab1 创作台**（任务类型：文生视频/图生视频/说话镜头/剧本故事片 · 提示词 · 参考图上传 · 分辨率/时长/音色/字幕 · 提交 · 状态/成片预览/下载/最近任务），
> **Tab2 样片墙**（8 部本机样片），**Tab3 能力与部署**（能力点/流程/三档硬件说明）。
> 后端抽象层 `studio/backend.py`：**demo**（默认，免费 CPU 档）/ **remote**（引擎网关 `REMOTE_API`+token）/ **local**（空间内 GPU 模型，预留）。
>
> **为什么别人的空间能直接生成？** 创空间免费档只有 2vCPU/16G（无 GPU，实测硬件列表：免费=platform/2v-cpu-16g-mem），
> GPU 为付费档（A10 24G ¥10.5/时、T4 16G ¥18.9/时）。别人的空间=**买了 GPU 档 + 跑小模型**（SD/SVD/AnimateDiff/Wan2.1-1.3B 等，
> 平台内网自动拉模型）或**调用云端 API**。我们的 H3（GB10 级）不适合塞进空间 → 推荐：
> ①**pages 前端（本页）** ②真实出片走 **GPU 档轻量模型** 或 **远程引擎网关**。

> 面向 GitHub 用户:本目录是一份**可独立部署到魔搭创空间(ModelScope Studio)的 Gradio 展示应用**:
> 一句话创意 → 参考图/提示词 → 本地大模型生成 → 真台词/字幕/旁白/口型成品链 → ASR 验收交付。
> 空间版本 **v1.3**(2026-09-09):故事片主控样片 + 台词先行/发音回环能力展示。

## 一、这是什么

一个 AI 视频生成工坊的**成品展示页**(免费 CPU 档,零生成依赖):

| 板块 | 内容 |
|---|---|
| 🎞 成品片墙 | 7 部本机生成样片(720p 直出/多参考图连贯/真台词无框/原声旁白/全链一体化/48fps 插帧/剧本→故事片),可播放、有封面 |
| 🧭 制作流程 | 灵感→提示词→生成→成品链→验收 五步(与真实引擎一致) |
| ✍️ 演示表单 | 剧情/台词/音色/风格/分辨率 → 匹配样片+格式说明(演示模式,不产生真实任务) |

**定位(2026-09-09 用户定案)**:创空间=**自包含静态展示+交互入口**(免费 CPU);完整生成能力在本机引擎
(MiniMax H3,GB10 40GB 模型,无法整体迁移云端)——空间通过样片与流程完整呈现能力面。

## 二、快速开始

### 本地(任意 Python 3.10+)

```bash
pip install gradio pyyaml
python app.py --port 7860
# 打开 http://127.0.0.1:7860
```

### 部署到魔搭创空间

1. 把本目录(studio/ 下的所有文件)**整体**放到一个 git 仓库(或直接上传 zip);
2. 创空间创建空间:选择 **Gradio SDK**,入口 `app.py`,Python 版本默认;
3. 提交构建 → 运行 → 页面内嵌展示(片墙可播放、演示表单可用);
4. 更新样式/样片后重新提交即可。

> 配置说明:创空间 sdk 配置读同目录 `config.yaml`(app_file/sdk_version/展示元数据);
> `app.py` 读取 config.yaml 的 `showcase` 段,缺失或损坏自动回退内建默认——**部署万无一失**。

## 三、能力说明(真实引擎侧)

- **生成类**:文生/图生/多参考图连贯(r2v)/首末帧转场;360p/480p/720p/768p/1080p;LoRA 加速档与全质档;
  夜间窗口(22:00-08:00 北京)自动执行 1080p/4x 超分重活。
- **故事片主控(2026-09-09 新增)**:剧本 JSON(标题/风格/故事背景/角色形象卡/分镜/台词表)
  → **单命令**出片:分镜提示词自动注入(背景+角色卡+本镜头人物+行为约束)→ 逐段 i2v 首帧继承 →
  台词先行(台词表文本,禁止现场编词)→ 发音回环(ASR≥0.70,不达标自动用发音写法重试)
  → 拼接(台词段保留音轨+字幕)。**断点续跑**:进度 JSON 逐段记录,中断/重启后同命令自动续跑。
- **成品链(2026-09-09 改版:无贴皮后处理)**:台词先行(台词表)→ **人物个性配音**（角色绑定音色:
  沉稳男/青年男/冷静女…+语速语气）→ 台词 TTS 替换原轨(降噪+响度归一)→ **字幕=台词原文**
  (语言跟随台词:中文台词=中文字幕、英文台词=英文字幕)→ ASR 发音回环(不达标自动 spoken 重试)。
  **不再做 Wav2Lip 贴皮口型/GFPGAN 修复**等后期加工(效果差);说话镜头如需要原生口型走 EchoMimic 生成侧驱动。
- **验收**:SenseVoice ASR 双轨验真(台词窗/旁白窗分别打分);性能证据:台词窗分数 0.92~1.00。
- **调度**:agent 任务调度器(定期/定点/服从安排;cron 五段+engine 直执/agent 注入+审计;
  动态计时按脚本体量;长任务断点续跑,无"超时中断重头")。

## 四、接口程序

- `runs/api/studio_gateway.py`:实验机联调网关(POST /v1/jobs、/v1/jobs/<id>、/v1/jobs/<id>/download、
  GET /healthz;/token 鉴权;/mock 与 /real 双模式)。
  定位=**工程师联调工具**;创空间正式交付=自包含展示(不依赖远程),无需配置远程。
- 演示表单在 `REMOTE_API`/`STUDIO_TOKEN` 环境变量**同时存在**时才走远程,否则自动演示模式。

## 五、配置与安全

- **无密钥、无远程依赖**:`REMOTE_API`/`STUDIO_TOKEN` 均为可选项,缺失自动降级(演示模式);
- 样片/封面为本项目自有生成;参考素材自备(不随仓库分发);
- 暴露端口仅 7860;Gradio allowed_paths 只开放本目录 assets。

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 页面空白/报错 | 查看空间日志;`pip install gradio pyyaml` 版本≥4.0;config.yaml 缺失可删(用内建默认) |
| 片墙不显示 | 确认 assets/ 与 app.py 同目录上传完整(7 组 mp4+cover) |
| 演示提交无反应 | 演示模式本就不产生任务;需要远程时配置 REMOTE_API/STUDIO_TOKEN(工程师联调) |
| 想换样片 | 替换 assets/0X_*.mp4 与封面,同步更新 config.yaml 的 showcase.samples(保持 style 键:电影感/真实/纪录片) |
