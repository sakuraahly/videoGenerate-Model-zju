# H3 视频创作 Agent · 魔搭创空间

> **形态（对齐课程要求）：本空间只部署 Agent，不部署模型；模型能力全部通过 API 接口调用外部服务。**
> 版本 **v3.1**（2026-09-10）。

## 这是什么

一个**对话式的视频创作 Agent**：你说一句需求（或给一张参考图、一句台词），它自己决定用哪个工具、
写什么提示词、用什么分辨率/时长/音色，然后调用**外部视频生成接口**出片，并把成片取回页面预览/下载。

- 空间地址：<https://www.modelscope.cn/studios/wumingyong0/Automated_video_generation>
- **设计想法与优点 → 见同目录 [`创作手记.md`](创作手记.md)**（老师要求的那份）
- **接口契约（怎么接外部 API）→ 见同目录 [`接口说明.md`](接口说明.md)**

## Agent 的两半（本交付的定义）

| 半边 | 内容 | 变量 |
|---|---|---|
| **工具集**（手脚，全部 HTTP，零本机依赖） | `generate_video`（文生/图生视频）、`generate_talk`（说话镜头）、`make_story_film`（剧本→多段故事片）、`list_jobs` / `query_job` / `retry_job` / `resume_story`（任务管理）、`answer`（答疑） | `TOOLSET` 可收窄 |
| **外置大脑**（决策） | OpenAI 兼容的 `/chat/completions`；模型只回一个 `{tool,args,say}` JSON | `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY`；平台 Agent 走 `AGENT_URL` |
| **视频生成** | 外部生成接口：提交 + 状态查询 | `ENGINE_BASE_URL` / `ENGINE_STATUS_URL` / `ENGINE_API_KEY` |

两半齐备即为完整 Agent；缺大脑时用内置**规则规划器**兜底（照样展示决策与请求体预览），
缺生成接口时进入**规划演示**——**不做假动作、不谎报成功**。

## 密钥怎么归属（三种，随你选）

1. **访客自带（BYOK）**：页面「🔑 我的密钥」填自己的模型服务地址/模型/Key；
   只在该会话内存里，**不写盘、不进日志**，按会话隔离，绝不会串用；
2. **零信任单页**（推荐给不信任运营方的人）：Agent 跑在访客浏览器里、直连其模型服务，
   **Key 不经过任何服务器** → <https://sakuraahly.github.io/videoGenerate-Model-zju/web/agent.html>；
3. **运营方体验额度**：空间变量里填一套 key（默认行为），访客填了自己的就优先用他的；
   设 `ALLOW_ENV_FALLBACK=0` 则空间**完全不提供**密钥（只发布工具）。

## 页面结构

- **🤖 Agent 对话**：说需求 → 工具调用轨迹 + 本轮产物 + 任务面板（可刷新状态）；
- **🎛 创作台**：表单式创作（任务类型/提示词/参考图/分辨率/时长/音色/字幕 → 提交 → 预览下载）；
- **🎞 样片墙**：本机全链产出的样片（含 ASR 分数、字幕、口型）；
- **🧭 能力与部署**：能力点、制作流程、部署说明、**🔌 测试外置大脑连接**（一键验证你的 key 通不通）。

## 安全加固（公开空间必需，v2.8+）

拒云元数据地址（SSRF）· 任务号白名单（防路径穿越）· 下载文件名清洗 · 上传与台账内存上限 ·
产物目录随机化（防跨用户猜链接）· 刷新与轮询限流 · 密钥不回显。

## 边界（如实说明）

- 空间**不产生真实生成任务**，除非配置外部接口或访客自填 key；
- **画质上限取决于你接的模型服务**（空间只做 Agent）；
- 空间内无持久化：会话结束即清（有意为之，不落任何用户数据）。
