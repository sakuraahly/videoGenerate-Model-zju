# 创作手记 · H3 视频创作 Agent（魔搭创空间）

> 这份手记按老师的要求写清两件事：**我们的 Agent 是怎么设计的（设计想法）**、**它好在哪里（优点）**。
> 空间地址：<https://www.modelscope.cn/studios/wumingyong0/Automated_video_generation>

## 一、一句话说清形态（对齐「创空间只放 Agent」的要求）

**本空间只部署 Agent，不部署任何模型**：空间里放的是「会调度的大脑 + 一套工具」，
模型能力（对话决策、视频生成）全部通过 **API 接口调用外部服务**——这正是老师说的
「留 api 接口可以调用外部 api 使用就可以了」。

```
创空间（免费 CPU，只跑 Agent）
  ├─ 外置大脑  LLM_BASE_URL / LLM_MODEL / LLM_API_KEY   （OpenAI 兼容；百炼/DeepSeek/魔搭都行）
  ├─ 平台 Agent AGENT_URL / AGENT_TOKEN                 （可选：社区指南里的“发布 Agent 只取 AGENT_URL”）
  └─ 视频生成  ENGINE_BASE_URL / ENGINE_STATUS_URL / ENGINE_API_KEY（外部生成接口，含状态查询）
```

为什么必须这样：免费档只有 2vCPU/16G、**没有 GPU**，而视频模型动辄几十 GB 权重——
空间做「入口 + 决策 + 任务面板」，算力交给外部接口，换机器/换模型只改环境变量。

## 二、设计想法（为什么这么做）

1. **用户要的是「出片」，不是「看参数」** → 交互做成对话式：直接说需求，Agent 自己选工具、定分辨率/时长/音色/字幕。
2. **痛点在「成品链」而不是「生成一下」** → 台词口型、字幕、时长匹配、验收，任何一环糊了就不可用；
   所以工具不是「一个生成函数」，而是把**成品链**封装成 `generate_talk`（说话镜头）/ `make_story_film`（剧本→多段故事片）。
3. **Agent = 工具集 + 外置大脑**（两半齐备才是 Agent）：
   - **工具集**（手脚，全部 HTTP，空间内零本机依赖）：`generate_video` / `generate_talk` / `make_story_film`
     / `list_jobs` / `query_job` / `retry_job` / `resume_story` / `answer`；`TOOLSET` 可收窄开放范围，越权调用被拒；
   - **外置大脑**（决策）：system 提示 + 可用工具与参数一起送进模型，模型只回一个 `{tool,args,say}` JSON；
     提示可外置注入（`AGENT_SYSTEM_PROMPT` / 文件），**换行业只改提示、不改代码**。
4. **要能比赛、也要能演出** → 没有 key 时也「像个 Agent」：内置**规则规划器**兜底，仍展示决策轨迹与请求体预览；
   有 key 立即切真实调用。**绝不空转、绝不假装成功、绝不抛报错栈给用户**。
5. **密钥不该由运营方垫** → 两条路：**BYOK**（访客在页面填自己的 key）与**零信任单页**（Agent 跑在访客浏览器里，
   key 不经过任何服务器）。详见第五节。

## 三、Agent 怎么跑（数据流）

```
用户自然语言
   ↓  [意图理解] 外置大脑（LLM_*/AGENT_URL）或 内置规则规划器（无 key 降级）
   ↓  产出结构化计划 {tool, args, say}
   ↓  [工具层]  8 个工具之一（全部是「真实动作」，不是话术）
   ↓  [执行层]  外部视频生成接口（未配置 → 规划演示：照样给出将发出的请求体）
   ↓  [回传层]  成片取回本地 → 页面内嵌预览 + 下载；任务面板记录本会话每次提交
   ↘  [可解释]  工具调用轨迹（模式/工具/参数/请求体/轮询）全程展示，评委可当场核对
```

## 四、能力与验收证据（不是 PPT 话术，是可复现的结果）

| 能力 | 做法 | 证据 |
|---|---|---|
| **说话镜头** | 先测台词**真实时长** → 按模型帧档定时长（音画同时长）→ 模型**原生音色**亲口说出 | ASR 回环 **1.000** |
| **字幕可控** | 字幕＝台词原文（不用转写，杜绝错字）；烧录/不烧录可选；位置贴底 | 交付样片有/无字幕各一版 |
| **剧本→故事片** | 剧本 JSON（角色卡+分镜+台词表）→ 一条命令出片；**台词先行**；改动只重做受影响段（断点续跑） | 短片《修好的收音机》多段连贯成片（720p） |
| **多参考图连贯** | 参考图契约 `<Picture N>` + 首帧继承；参考图**不是首末帧** | 多张参考图全片锁定 |
| **质量闸门** | 视觉模型逐帧验收「画面里有没有模型自绘字幕」→ 有则裁底/换种子重生成 | 成片无叠字事故 |
| **验收即交付** | ASR 双窗验真（台词窗/旁白窗），不达标自动改发音写法重试 | 每部样片带 ASR 分数 |

## 五、优点（为什么这套设计靠谱）

1. **零本机依赖、可移植**：不读本机路径、不调本机脚本、不依赖内网地址；换机器/换服务只改环境变量——所以它才能当交付件。
2. **可换脑、可换引擎**：任何 OpenAI 兼容服务（百炼 / DeepSeek / 魔搭 / 自建 vLLM）都能当大脑；
   视频侧也只要实现「提交 + 状态查询」两个接口即可接入。**不被某一家厂商绑死**。
3. **密钥三种归属随你选**：① 访客自带（BYOK，按会话隔离、不落盘、不进日志）；
   ② **零信任单页**（浏览器直连模型服务，key 不经过任何服务器）；③ 运营方给体验额度。
4. **可解释**：每次回答都附工具调用轨迹与将发出的请求体，决策过程对评委完全透明。
5. **诚实降级**：没配接口 → 规划演示（不做假动作）；谎报「已提交」→ 系统按工具调用记录驳回；
   状态查不到 → 明确标注「显示的是本会话记录」，**不编进度**。
6. **有工程保障**：单元测试 **289 项**（覆盖工具集、大脑通道、接口协议、作业台账、安全边界）；
   一键部署（平台 OpenAPI 触发重建）；定时自检与清理；任务断点续跑。
7. **有安全加固**（公开空间必需）：拒云元数据地址（SSRF）、任务号白名单（防路径穿越）、文件名清洗、
   上传与台账内存上限、产物目录随机化（防跨用户猜链接）、刷新与轮询限流。

## 七、怎么玩（评委 60 秒上手）

1. 打开空间 → **Agent 对话**：先上传一张人物参考图，输入「让参考图里的老人说一句『天冷了，快进屋坐坐吧』」
   → 看它选 `generate_talk`、把图转成 `image_b64`、并给出将发给接口的请求体；
2. 输入「做一段雨夜老屋门口有猫的 5 秒镜头」→ 看它切 `generate_video`；
3. 输入「现在有哪些任务 / 刚才那个好了吗」→ 看它调用 `query_job` / `list_jobs`；
4. 输入「怎么做到不部署模型？」→ 看它走 `answer` 解释架构；
5. 想看真东西：**样片墙**里都是本机全链产出（带 ASR 分数、字幕、口型）；
6. 想验证「是不是真在调接口」：点 **🔌 测试外置大脑连接**，填上自己的 key 立刻能看到真实调用与耗时。

## 八、边界（如实说明）

- 空间**不产生真实生成任务**，除非配置了外部接口（或访客自填 key）；
- 空间不部署模型，**画质上限取决于你接的模型服务**；
- 外部接口需要按契约实现（提交 + 状态查询）；参考图上传走 `image_b64`，大图请自行压缩；
- 面向使用者**不暴露任何服务器路径与内部细节**，只说「结果在哪、能不能用」。
