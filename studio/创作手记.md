# 创作手记 · H3 视频生成工坊（创空间 Agent）

> 作者：本项目（视频生成工作流 + Agent 调度）；空间版本 v2.0（2026-09-10）

## 一、我们做的是什么（一句话）
把"一句话创意 / 一张参考图 / 一句台词"变成**能直接看的成片**的 Agent——
**创空间里放的是 Agent（前端大脑），模型不放进来，全部通过 API 调用外部算力。**

## 二、为什么这样设计（想法来源）
1. **算力现实**：创空间免费档只有 2vCPU/16G、无 GPU（实测硬件列表：免费仅 `platform/2v-cpu-16g-mem`），
   而视频生成模型动辄几十 GB 权重。—— 所以**空间=入口与大脑，算力=外部 API**，这也是课程建议的部署方式。
2. **用户要的是"出片"，不是"看参数"**：于是把交互做成**对话式**：直接说需求，Agent 自己决定
   用哪个工具、什么分辨率/时长/音色、要不要字幕。
3. **生成的痛点在于"成品链"而不是"生成一下"**：台词口型/字幕/时长/验收，任何一环糊了就不可用。
   我们把这条链做成了可验收的工程闭环（见下）。
4. **要能比赛、也要能演出**：没有 API key 时也必须"像个 Agent"——所以内置**规则规划器**，
   无 key 也能展示决策轨迹与匹配样片，有 key 立即切真实调用。

## 三、Agent 设计
```
用户自然语言
   ↓
[意图理解] LLM（OpenAI 兼容接口，可配置）或 内置规则规划器（无 key 降级）
   ↓ 产出结构化计划 {tool, args, say}
[工具层]  generate_video | generate_talk | make_story_film | answer
   ↓      （工具=外部能力封装：视频生成 API / 台词口型 / 多段故事片 / 答疑）
[执行层]  外部视频 API（可配置 URL+Token）；未配置 → 规划演示（展示将执行的参数）
   ↓
[回传层]  结果卡 + 成片预览 + 下载 + 最近任务；并把**工具调用轨迹**（mode/tool/args）展示给用户
```
- **可解释**：每次回答都附"工具调用轨迹"，评委能直接看到 Agent 的决策与参数，而不是黑箱。
- **优雅降级**：LLM key 缺失 → 规则规划器；视频 API 缺失 → 规划演示 + 样片；任何异常都回一句人话而不是报错栈。
- **后端可切换**：`STUDIO_BACKEND=demo|remote|local`；同一前端可对接：免费 CPU 演示 / 外部 API / 自建引擎网关 / （未来）空间内 GPU 小模型。

## 四、Agent 的"成品链"能力（本项目的硬功夫）
这些能力已经在样片里可见（空间「样片墙」8 部均为本机生成）：
| 能力 | 做法 | 验收证据 |
|---|---|---|
| **台词说话镜头** | 先本地 TTS 得到台词**真实时长** → 按模型帧档生成（音画同时长）→ 模型**自适应音色**亲口说出 | ASR 回环 **1.000**（"真是力不从心了, what can I say?"） |
| **字幕可控** | 字幕=台词原文（不用识别转写，杜绝错字）；**可选烧录/不烧录** | 交付样片无字幕版/有字幕版各一 |
| **剧本→故事片** | 剧本 JSON（角色卡+分镜+台词表）→ 单命令出片；**台词先行**；改动只重做受影响段（断点续跑） | 希区柯克《油价涨了》9 段 48s |
| **多参考图连贯** | 参考图契约（`<Picture N>`）+ 首帧继承；0 基编号自动归一 | 3 张参考图全片锁定 |
| **验收即交付** | SenseVoice ASR 双窗验真（台词窗/旁白窗）；不达标自动用发音写法重试 | 每部样片均带 ASR 分数 |

## 五、工程优点（可复现、可维护）
- **免 GPU 即可运行**：空间免费档实测 HTTP 200、页面完整（创作台/样片墙/能力说明）。
- **一键部署**：平台 OpenAPI（`POST /studios/{owner}/{repo}/deploy`）触发重建，代码经 Git 同步。
- **有测试**：单元测试 200+（含 Agent 调度 cron、清理工具、后端抽象、参考图契约、台词链等），
  关键逻辑（如 0 基编号、Windows 路径保护）都由测试兜住。
- **有运维**：定时任务（每周自动清理日志/临时文件）、调度器自检、任务断点续跑、
  "提交真实性校验"（Agent 谎报提交会被系统驳回）。
- **成本可控**：平时用免费 CPU 展示与规划；需要真实出片时按需接外部 API 或切 GPU 档，不用即停。

## 六、边界与后续
- 当前空间**不产生真实生成任务**，除非配置 `LLM_*` / `VIDEO_API_*`（外部 API）或切到 GPU 硬件档。
- 后续路线：①接外部视频 API（推荐，成本低）②自建引擎网关 `REMOTE_API`（保留本机 H3 全链质量）
  ③空间内轻量模型（Wan2.1-1.3B / CogVideoX-2B，需付费 GPU 档）。
- 我们坚持的一条底线：**面向用户不暴露任何服务器路径/内部细节**，只说"结果在哪、能不能用"。

## 七、怎么玩（评委快速上手）
1. 打开空间 → **Agent 对话**：输入"让参考图里的老人说一句'天冷了，快进屋坐坐吧。'"→ 看它选 `generate_talk` 并组参数；
2. 输入"做一段雨夜老屋门口有猫的 5 秒镜头"→ 看它切 `generate_video`；
3. 输入"怎么做到不部署模型？"→ 看它走 `answer` 解释架构；
4. 想看真东西：**样片墙**里 8 部都是本机全链产出（含 ASR 分数、字幕、口型）。
