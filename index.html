H3 视频 Agent · 工具发布入口

这里发布的是**工具**，不是服务：密钥、算力、模型额度都由使用者自己提供。

① 零信任单页 Agent（推荐）

打开 web/agent.html，在页面里填你自己的模型服务地址 / 模型名 / API Key。

你的 Key 只在这个浏览器里使用：页面直接调用你填的服务（浏览器跨域直连），不经过任何第三方服务器。

② 创空间在线版（演示 + BYOK）

魔搭创空间：可在页面「🔑 我的密钥」里填自己的 Key；也可只看演示（不填不发请求）。

③ 自己部署（最彻底）

把本仓库 git clone 到你的机器/服务器，用你自己的密钥运行，任何数据都不出你的环境。
