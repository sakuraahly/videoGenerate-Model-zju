🧰 工具集与提示词契约（agent 会从这四个里选）
  • generate_video：文生视频；带参考图则图生视频（prompt / resolution / seconds / image_b64）
  • generate_talk：说话镜头——人物亲口说出台词（text / voice / image_b64）
  • make_story_film：剧本 → 多段连贯短片（script / segments / resolution / seconds）
  • answer：只答疑不生成（text）

参考图契约（r2v 语义）：提示词写 <Picture 1>…<Picture N> 对应每张参考图，并写明“参考图贯穿全片、不是首末帧”。
