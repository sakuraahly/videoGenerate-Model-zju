# 03 · 别人怎么用（怎么保证可用性）

> 这是本次说明书的重点：**凭什么说别人能用得起来**。

## 0. 结论：四条路径，覆盖四类人

| 用户类型 | 他要做什么 | 我们能保证什么 |
|---|---|---|
| **A. 完全不想折腾**（只想看看） | 打开链接，说一句话 | 不填任何东西也能看到「选哪个工具、什么参数、请求体长什么样」——不联网、不花钱、不报错 |
| **B. 有自己的模型 key** | 页面填 3 项（选预设 + 贴 Key） | 立刻真实调用；key 只在该会话内存，2 小时回收 |
| **C. 不想把 key 给任何服务器** | 打开零信任单页 | Agent 跑在他浏览器里，key 不经过我们 |
| **D. 要自己掌控 / 接自己 GPU** | `git clone` 本地跑 | 一条命令启动；两条接口填自己的地址即可 |

## A. 完全不想折腾的人（零配置路径）

1. 打开空间 → 顶部提示「**本空间不提供自带密钥：请在「🔑 我的密钥」里填你自己的**」；
2. 直接在对话框说「让参考图里的老人说一句『天冷了』」或「做一段雨夜老屋门口有猫的 5 秒镜头」；
3. 他会看到：
   - 内置**规则规划器**（关键词判定）选出 `generate_talk` / `generate_video` / `make_story_film`；
   - 给出**参数**与**将发给视频接口的请求体预览**；
   - 右侧**任务面板**与**调用轨迹**照常展示；
4. 不会发生：不联网、不产生任务、不报错栈、不假装出片（明确写「演示模式 / 未配置接口」）。

**为什么保证得了**：规则规划器与 LLM 通道**产出结构完全一致**（同一个 `{tool,args,say}`），
所以没有 key 只是「决策来源不同」，流程一点都不缺。

## B. 有自己的模型 key 的人（30 秒路径）

1. 展开「🔑 我的密钥」→ **① 选服务商**（百炼 / DeepSeek / 魔搭 / 智谱 / 自定义）→ 地址与模型名**自动填好**；
2. **③ 贴 API Key** → 点「🔌 测试外置大脑连接」；
3. 看到 `✅ 大脑可用：自建大脑（LLM_*）｜模型 qwen-plus ｜ xxx ms ｜ 回话：可用` 就说明通了；
4. 回对话区说需求 → 真实调用 → 出请求体 → 若他还填了视频接口，就能真出片。

**保证措施**：
- 三家主流服务商**实测允许直连**（百炼 `ACAO:*`、DeepSeek 回显 Origin、魔搭 `ACAO:*`）；
- 地址填错 / 额度用尽 / 被限流 → 页面给**人话排查**（① 地址/Key ② 跨域 ③ 额度），不抛异常堆栈；
- key **不写盘、不进日志**，只在内存；有 TTL 与总量上限；
- 会话之间**互不可见**（每个会话独立客户端实例）。

## C. 不信任运营方的人（零信任路径）

链接：<https://sakuraahly.github.io/videoGenerate-Model-zju/web/agent.html>（GitHub Pages 公开托管）

1. 打开页面 → 填「模型服务地址 / 模型名 / API Key」（预设同 B）；
2. Agent 逻辑（工具选择 + 参数）在**浏览器里**跑，请求**直发他填的服务**；
3. 选好工具后给出**视频接口请求体**：可「复制 curl」在自己机器上跑，或「用我的引擎直接跑」由浏览器直发他的网关；
4. 勾选「记住到本浏览器」才写 `localStorage`（仅本机），不勾则关页面即失效。

**为什么叫零信任**：页面请求**只发往他填的两个地址**，不经过我们任何服务器；
单文件 HTML、无第三方脚本/统计/CDN，可另存自托管。

## D. 要自己掌控的人（自部署路径）

```bash
git clone https://github.com/sakuraahly/videoGenerate-Model-zju.git
cd videoGenerate-Model-zju/studio
pip install -r requirements.txt
python app.py --port 7860      # 打开 http://127.0.0.1:7860
```

- 不填任何接口 → 规划演示；填上两条接口 → 真实出片；
- 接自己的 GPU：实现「提交 + 状态查询」两个动作（见 02-接口契约），或把本仓库 `h3_submit.py` 包一层网关；
- 换大脑：任何 OpenAI 兼容服务；
- **创作台表单**走 `backend.py`（demo/remote），Agent 对话走 `ENGINE_*` 契约，两条路可并存。

## 验收清单（判断「别人能不能用」的标准）

| # | 检查项 | 期望结果 |
|---|---|---|
| 1 | 打开空间（不带 key） | 页面正常、顶部有「不提供自带密钥」提示 |
| 2 | 说一句需求（不带 key） | 给出工具 + 参数 + 请求体预览，不报错 |
| 3 | 选服务商 → 填自己的 key → 点自测 | `✅ 大脑可用 … ms` |
| 4 | 用自己的 key 说需求 | 得到真实工具决策（LLM 通道） |
| 5 | 打开零信任单页 | 填 key 后能拿到计划与请求体 |
| 6 | F12 看网络请求 | 除他填的地址外**没有任何出站请求** |
| 7 | 刷新页面 / 换会话 | key 需重填（不持久化）；任务台账按会话隔离 |

## 失败时的表现（都已经写好人话）

| 情况 | 页面表现 |
|---|---|
| 没填 key | 规则规划器接管，明确标注「规划演示」 |
| key 错 / 额度尽 | `❌ 大脑不可用：…原因：401 Unauthorized`，并给排查方向 |
| 视频接口没配 | 「只能出方案预览，点生成不会真出片」 |
| 视频接口超时 | 「任务已提交，还在生成中」+ 可用任务号去查 |
| 引擎不支持续跑 | 直接说「接口未提供断点续跑能力，只能整段重提」 |
