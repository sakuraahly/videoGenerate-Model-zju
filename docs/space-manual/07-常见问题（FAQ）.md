# 07 · 常见问题（FAQ）

**Q1 空间里为什么不放模型？** 免费档 2vCPU/16G 无 GPU，视频模型几十 GB；课程也要求留 API 接口调外部。

**Q2 我没填 key，能用吗？** 能看不能用（不出片）：规则规划器照样给工具、参数与请求体预览，不联网、不花钱。

**Q3 我怎么让它真出片？** 两条接口都配上：大脑（任何 OpenAI 兼容服务）+ 视频接口（提交 + 查询）。

**Q4 视频接口要写多少代码？** 两个动作：`POST` 提交返回 `job_id`；`GET {status}/{job_id}` 返回状态与 `video_url`。

**Q5 工作流上传到空间了吗？** 没有。工作流只在 GPU 机器上，空间与本机之间只传接口字段。

**Q6 我能用自己的模型吗？** 能。页面「我的密钥」选「自定义」填地址与模型名即可（任何 OpenAI 兼容服务）。

**Q7 我不想把 key 交给你们怎么办？** 用零信任单页版：Agent 跑在浏览器里直连你的服务。

**Q8 密钥会被保存吗？** 不会。只在会话内存，2 小时回收；不写盘、不进日志；按会话隔离。

**Q9 为什么有时只回一句「还在生成中」？** 引擎是异步的，超过等待时长就先返回任务号，可用「查作业」或刷新面板跟进。

**Q10 任务失败了能重试吗？** 能，`retry_job` 用原请求体重提，可换 seed / 时长 / 分辨率。

**Q11 能中途接着跑吗？** 只有引擎声明支持 `resume_from`（`ENGINE_RESUME=1`）才行；否则空间会如实说只能整段重提。

**Q12 为什么页面有时说「显示的是本会话记录」？** 状态接口没答上来时不编进度，只显示已知信息并标注来源。

**Q13 样片是真的吗？** 是，样片墙 8 部都是本机全链产出（含台词、字幕、ASR 分数）。

**Q14 空间和开源仓库什么关系？** 仓库是**工具**（代码 + 工作流），空间是这个工具的**在线 Agent 形态**；要自己掌控就 clone。

**Q15 我要给朋友的 key 提个醒吗？** 建议：填自己的 key、用完可删；空间侧不保存任何密钥。
