## 精华（一页速览）

1. **空间 = Agent，不是模型**：免费 CPU 档（2vCPU/16G、无 GPU）里只跑「会调度的大脑 + 一套工具」，
   模型能力全部走**外部 API**（这也是课程要求：留接口调外部）。
2. **两条接口就够**：
   - 大模型：任何 **OpenAI 兼容**服务（百炼 / DeepSeek / 魔搭 / 智谱 / 自建 vLLM）；
   - 视频：`POST {ENGINE_BASE_URL}` 提交 → 返回 `job_id`；`GET {ENGINE_STATUS_URL}/{job_id}` 查状态 → 返回 `video_url`。
3. **别人为什么能用得起来**（关键）：
   - **零配置也能用**：不填 key → 规则规划器照样给出「用哪个工具、什么参数、请求体长什么样」；
   - **填 3 个字就能真跑**：页面「🔑 我的密钥」→ 选服务商（自动填地址与模型名）→ 贴 API Key；
   - **不想给 key 也行**：零信任单页版，Agent 跑在他自己浏览器里，key 不经过任何服务器；
   - **想彻底自己掌握**：`git clone` 本仓库，本地 `python app.py` 就能跑。
4. **不花你一分钱**：空间变量里没有任何密钥（`ALLOW_ENV_FALLBACK=0`），访客自带 key；
   运营方若要给体验额度，填回 `LLM_*` 即生效，并有「每小时每会话 60 次」的限流兜底。
5. **空间里没有工作流**：ComfyUI 工作流只在本机 GPU 机器上，空间与本机之间**只传接口字段**（`kind/prompt/image_b64/…`）。
6. **数字**（2026-09-11 核验）：8 个工具 · 5 个 Agent 角色 · 108 套分镜骨架 · 生产包 9 个文件 · 单元测试 **506 项**（`py -3 -m pytest tests -q`）· 台词 ASR 回环 **1.000** · 空间零密钥零成本形态。
