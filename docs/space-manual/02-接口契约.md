# 02 · 接口契约（两条接口，照着填就能用）

## 一、大模型接口（Agent 的「大脑」）

**形态**：OpenAI 兼容 `POST {LLM_BASE_URL}/chat/completions`（任何兼容服务都能用）。

### 页面填（推荐，访客自己填）

「🔑 我的密钥」三步：① 选服务商（自动填地址与模型名）→ ② 核对地址/模型名 → ③ 贴 API Key。

| 预设 | `LLM_BASE_URL` | `LLM_MODEL` |
|---|---|---|
| 阿里云百炼（DashScope 兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| 魔搭 API-Inference（社区免费额度） | `https://api-inference.modelscope.cn/v1` | 例如 `Qwen/Qwen3.5-35B-A3B` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 自定义 | 你自己的兼容端点 | 你的模型名 |

### 变量填（运营方给默认值时）

| 变量 | 说明 |
|---|---|
| `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY`（密钥区） | 默认大脑；**建议留空**（见 05-安全与密钥） |
| `LLM_EXTRA_JSON` | 额外请求字段，例 `{"enable_thinking": false}`（关思考更快） |
| `AGENT_URL` / `AGENT_TOKEN` | 平台 Agent 通道（社区指南形态），**优先级高于 `LLM_*`** |
| `ALLOW_ENV_FALLBACK` | `0` = 空间完全不提供自带凭据（零成本形态，当前设置） |
| `BRAIN_CALLS_PER_HOUR` | 大脑调用限流（只对运营方凭据生效；默认 60 次/会话/小时，0=不限） |

### 空间发给大脑的请求体

```json
{
  "model": "qwen-plus",
  "messages": [
    { "role": "system", "content": "<默认铁律提示> + 可用工具(JSON 列表)：8 个工具 schema" },
    { "role": "user",   "content": "<最近 6 轮对话 + 本轮输入>" }
  ],
  "temperature": 0.3,
  "response_format": { "type": "json_object" }
}
```

**模型必须只回一个 JSON**：

```json
{ "tool": "generate_talk", "args": { "text": "天冷了，快进屋坐坐吧。", "voice": "native" }, "say": "给用户的一句说明" }
```

空间拿到后：校验工具是否在开放集合内 → 参数归一化 → 拼请求体 → 执行。

- 推理型模型（如 `deepseek-reasoner`）不支持 `temperature`：空间**自动去掉**；
- 模型把 JSON 包在解释文字/代码块里：空间**容错解析**（剥代码块 + 取第一个完整 JSON 对象），不因此判失败。

## 二、视频生成接口（两个动作）

| 变量 | 含义 |
|---|---|
| `ENGINE_BASE_URL` | **提交**：`POST`，返回 `{"job_id": "..."}`（也接受 `task_id` / `id`） |
| `ENGINE_STATUS_URL` | **查询**：`GET {ENGINE_STATUS_URL}/{job_id}`，返回 `{"status":"running|completed|failed", "video_url":"...", "progress":0.42}` |
| `ENGINE_API_KEY` | 鉴权：以 `Authorization: Bearer <key>` 发送（密钥区） |
| `ENGINE_SYNC_WAIT` | 提交后等待秒数（默认 120，`0`=立即返回任务号）；超时回「还在生成中」而不是卡死 |
| `ENGINE_RESUME` | `1` = 引擎支持 `resume_from`（断点续跑）；不填则 `resume_story` 会**如实拒绝** |

### 提交请求体（Agent 自动拼好，你只需实现服务端）

| 字段 | 取值 |
|---|---|
| `kind` | `t2v`（文生视频）/ `i2v`（图生视频）/ `talk`（说话镜头）/ `story`（多段故事片） |
| `prompt` | `kind=t2v/i2v` 的提示词 |
| `text` / `voice` | `kind=talk` 的台词原文与音色（默认 `native`） |
| `script` / `segments` | `kind=story` 的剧本与段数 |
| `image_b64` | 参考图，`data:image/png;base64,...` |
| `resolution` / `seconds` | 分辨率档位与时长 |

**示例**：

```bash
curl -sS -X POST https://你的网关/v1/jobs \
  -H "Authorization: Bearer $ENGINE_API_KEY" -H "Content-Type: application/json" \
  -d '{"kind":"talk","text":"天冷了，快进屋坐坐吧。","voice":"native","resolution":"480p"}'
# → {"job_id": "abc123"}

curl -sS https://你的网关/v1/jobs/status/abc123 -H "Authorization: Bearer $ENGINE_API_KEY"
# → {"status":"completed","video_url":"https://…/film.mp4"}
```

### 本地先跑通（不花钱）

仓库里有假引擎 `tests/mock_engine.py`：起一个进程即扮演「引擎 + 大脑」，
用来验证「Agent → 请求体 → 轮询 → 取回成片 → 页面预览」整条链，再换成你自己的服务。

## 三、契约的两个红线

1. **空间不发送工作流**：只发上表字段；工作流留在你自己机器上；
2. **状态接口要如实**：查不到就报错，空间会标注「显示的是本会话记录」，不会编进度。
