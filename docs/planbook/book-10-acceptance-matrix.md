## 2. 全局回归清单（发布前勾选，合并自 book-09 §4）

- [ ] 上传大图(>4MB)：≤数秒 + 缩略图 + 状态提示。
- [ ] 上传幂等：重选同批跳过/不重复。
- [ ] 新会话/加载历史：即时；“加载所选历史会话”“删除所选历史会话”正确。
- [ ] 发送清空+锁：处理中点发送被忽略。
- [ ] 状态条：长任务持续更新；显示版本指纹/配置漂移告警（若实现）。
- [ ] 中止本轮：快速收尾、可再发。
- [ ] LLM 流式/分块：逐块出现，非一次性暴长；回复中文；英文原文保留。
- [ ] 输出截断自动续跑：不再半途中止等用户。
- [ ] 多图转场：10 图→逐段/批量多段；各段提示词不同、产物不同；取片+拼接清单完整。
- [ ] 资源隔离：不同会话不上传互见；旧任务产物默认不出现；“最新/本任务所需”可识别。
- [ ] 工作流提示词：video_* 仅质量 token；注入的是自动生成的段提示词。
- [ ] 批量/引擎：h3_batch 不 ModuleNotFoundError；status 不假超时；参数契约明确。
- [ ] 错误提示：分类+建议。
- [ ] nap/wake：提交后 LLM 让位→自动唤醒。
- [ ] 产物边界：LOCAL_OUTPUT 与 outputs/ 一致；不把旧片当新结果。
- [ ] 异常取证：红错→文本+状态行+日志回写。

## 3. 风险与回滚速查

| 阶段 | 主要风险 | 回滚方式 |
|---|---|---|
| 0 基座 | sync_to_spark 覆盖两端本应不同配置；版本指纹崩溃 | 保持增量；try/except 兜底版本；回退上一稳定 commit |
| 1 前端 | Gradio 版本/组件差异致改动不生效 | 起临时实例自测（--port 7861）；纯文案 git 回退；新控件可开关 |
| 2 输出 | 过度约束中文误伤提示词 | 豁免「提示词本体」；打字机不回退后端 |
| 3 自动完成 | 自动续跑造成重复提交 | turn_state/session_state 幂等判重；提交类成功即结束本轮 |
| 4 隔离 | 过度隔离使复用历史产物变难 | scope=all 显式开关；不迁移/删除产物 |
| 5 工作流 | 删故事后画面变差；UI↔API 丢 prompt | dry-run 先验；git 还原模板；回退到原 story |
| 6 引擎 | 逐段注入后画面不可控；超时对齐影响提交语义 | 先单段真跑；保持 submit-only；逐项回退 |
| 7 风格 | 过早“拍板”忽略用户偏好 | 保留「内容/素材」提问界；SYSTEM_MESSAGE 可整体回退 |
| 8 验证 | 无真实执行证据误判通过 | 一律回到“无 SMOKE_OK/黄金路径证据=未完成” |

## 4. 依赖与顺序总结

- **第 0 步（立即止血，2026-09-04 已确认真因）**：spark 磁盘代码正确但 7860 进程比代码早 2 小时（`06:18` 启动 vs `ui_app.py 08:18` 落盘）→ 按 **`docs/dev-workflow.md §6.1`**（tmux 会话 = `agent`，**不是** `qwen-agent`）重启，并以「端口持有者启动时间 ≥ 重启时刻 + `/config` 新文案 + 版本指纹」验证；此步即可让「界面没改」消失。
- **先**：book-01（基座，确认 spark 跑的版本、建立可重复部署/可信验证门禁——版本指纹自报是防再次假绿的关键）。
- **低耦合先行**：book-02（前端，不改后端）。
- **再**：book-03/04（输出语言/流式/自动完成）。
- **然后**：book-05（资源隔离）→ book-06（工作流提示词/注入）→ book-07（批量/引擎）。
- **并行/随行**：book-08（风格，交互式需用户任务）与 book-09（验证，每个阶段按它验收）。
- 里程碑验证：建议在「前端+输出」与「隔离+工作流+引擎」两组完成后各跑一次完整黄金路径（book-09 层级 3）。

## 5. 整件事的「完成」定义

要判定整个修复“完成”，须同时满足：
1. 两端一致：Windows 主库 commit → GitHub → spark 运行时，版本指纹一致（book-01）。
2. 黄金路径端到端：上传→选素材→逐段提示词→提交→取片→拼接 全程复现，各段不同，证据留痕（book-09）。
3. 用户体验达标：界面友好、中文流式、任务自动完成、本会话只见自己素材（book-02/03/04/05）。
4. 引擎稳定：h3_batch/batch_submit 无导入/超时/卡死（book-07）。
5. 风格可控：agent 不多问、自主完成、中文结论先行（book-08）。
6. 未越红线：未动 ComfyUI 服务/模板/同事模板；未引入 api_*；未写 Z: 盘。
