## 1. 问题背景（用户可见现象）
- 「agent 总是纠结于一些细枝末节。」「之后我会发送一次完整的对话任务内容给你，你需要通过修改系统提示词和 skills 限制技能来控制模型的风格。」

---

## 2. 根因分析（针对 `runs/agent/scheduler.py` 的 SYSTEM_MESSAGE）

### 2.1 现系统提示的关键措辞（`scheduler.py:45-110`）
- 「**自主行动优先**：用户给出创意后，你应自主选择工作流、生成详细英文提示词、选择参数、直接提交。不要反复确认技术细节。」
- 「**只问必要问题**：仅在以下情况询问用户——①视频内容/主题完全不明确 ②需要用户从素材中选择参考图 ③分辨率/时长偏好不确定且无法合理推断。其他一切技术细节由你决定。」
- 「**工作到完成**：提交任务后不要停下来等用户指示。如果还有后续步骤（生成下一段、检查进度、获取结果），继续执行。」
- 「**能**说继续=承接上次工作」；「**创意→成片**：只给一句创意时直接……提交。」

### 2.2 为何仍会纠结细枝末节
- 「只在……才问」的三个触发**较抽象**，模型难以判定「不明确/无法合理推断」，容易反复确认、或对「内容/主题/偏好」过度斟酌。
- 系统提示同时含**大量技术细节**（分辨率/时长/帧数网格/音频分层/负面约束收尾/多图转场），模型容易「叙述一遍技术过程」而非「简短汇报」。
- 「生成详细英文提示词」与 ctx=8192「单轮 ≤600 字」互相拉扯，模型可能把大量篇幅花在提示词/参数解释上，显得啰嗦、纠结。
- 没有给「何时该停下来问一句」的**明确示例/判定清单**，也没有给「决策优先级」：内容>参数>措辞。

## 3. 目标与范围

**目标**：让 agent 自主、果断、完成导向；只在真正影响产出时问；回复简短、结论先行、带依据；不纠结默认值/技术细节/措辞。

**做**：
- 收紧「必要问题」：给出**明确触发清单 + 反例**（哪些**不要**问），并给「决策优先级」：内容/创意是否清晰 → 素材由谁定 → 其余参数由你定。
- 给「什么算细节别纠结」的**反例**：不要问分辨率/时长/seed/镜头/音频是否 OK；不要复述你打算怎么调用工具；不要逐条说明参数取舍。
- 加「完成导向」行为：只要还能推进就推进；确需用户输入时才停，且**一次只问一个最关键的**，别一次抛一堆问题。
- 加「汇报风格」：结论先行、一带依据（TASK_SUBMITTED/路径/产物号）、中文、简短。
- 与 `skills/h3-video-generation.md`、`docs/agent-reading/02/04` 同步该口径，避免技能卡又教出一堆英文细节。
- 用户将提供一次完整对话任务 → 用其做「风格回归」：记录 agent 是否多问/是否完成/是否中文，据此微调措辞。

**不做**：不做破坏功能安全的改动（仍不越权、不改服务）；不改变「提示词必须英文」。

## 5. 实施步骤

### 步骤 1：定「必要问题」判定清单
- 只允许以下触发提问：①用户没说要生成什么（无主题/内容）；②用户明确提到“从我的素材”里选，但未指明哪张（需用户点选）；③用户指定的时长/分辨率**与项目上限冲突**（需确认）。
- 明确**禁止**以下提问：分辨率/时长默认值、seed/steps/fps、镜头/音频描述、参考图槽位号、调用了什么工具、参数取舍说明。

### 步骤 2：写「决策优先级」与「汇报风格」
- 优先级：内容/创意清晰度 > 所需素材是否可推断 > 其余一切参数你定。
- 汇报：结论先行 + 一行依据；中文；≤600 字；不逐条解释技术过程。

### 步骤 3：写风格样例（style-guide.md）
- 好：`已生成英文提示词并提交。prompt_id: xxx。需要取片可以说“继续”。`
- 坏：`我选择了 t2v 阶段，分辨率 720p，时长 5s，seed 我设成……因为……现在调用……工具……`。

### 步骤 4：与 skills/agent-reading 同步
- 把上述「别纠结细节、结论先行、中文、一次只问一个」写入 skill 与 agent-reading。

### 步骤 5：用真实对话回归（用户提供后）
- 用用户提供的完整任务跑一遍；记录是否多问、是否自主完成、是否中文；据此微调 SYSTEM_MESSAGE 措辞（如某类问题反复出现则加反例）。

## 6. 验收标准（真实对话）

- [ ] 用用户提供的完整任务，agent 未问“分辨率/时长/seed/镜头/是否 OK”这类可自决问题；只在下述关键处（内容不明/需点选素材/与上限冲突）问。
- [ ] agent 能自主推进到提交/取片，不中途停下等确认（除非确需用户输入）。
- [ ] 若确需问，**一次只问一个**最关键问题，而非抛一串。
- [ ] 回复中文、结论先行、带依据；不逐条解释技术过程。
- [ ] 生成提示词仍为英文；不因风格改动破坏提示词规则。

## 7. 风险与回滚
- **风险：收紧提问导致素材选错/参数越限**——保留「与上限冲突需确认」与「需用户点选素材」两个必要出口；对默认值由系统兜底（memo 默认 720p/5s）。
- **风险：风格改动过强导致过早“拍板”而忽略用户真实偏好**——以「内容/素材」为提问界，其它默认即可。
- **回滚**：SYSTEM_MESSAGE/skill/agent-reading 均为文本，可整体回退；风格回归有记录可查。
