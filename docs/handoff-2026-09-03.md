## 6. 技术决策记录

### 6.1 为什么核心知识嵌入 system prompt 而不是强制读取？
**考虑**：
- 强制读取消耗 tokens 和时间（每次任务前先读 4 个文件）
- Agent 可能忘记读取或读取失败
- 核心知识相对稳定，不需要频繁更新

**决定**：核心知识嵌入 + `read_doc` 作为可选深入参考。
**权衡**：system prompt 变长（~1500 tokens），但节省每次任务的读取开销。

### 6.2 为什么 Open WebUI 和 Qwen-Agent 分开部署？
**考虑**：
- Open WebUI：功能丰富的 ChatGPT 风格界面，支持 RAG、多模型、历史记录
- Qwen-Agent：阿里官方框架，支持工具调用、function calling

**决定**：两者并存，各司其职。
- Open WebUI (3000)：日常对话、知识问答、RAG 检索
- Qwen-Agent (7860)：视频/图片生成任务、工具调用

### 6.3 为什么 RAG 默认启用？
**背景**：之前显式禁用 `ENABLE_RAG=false`，因为 embedding 模型下载问题。
**现状**：embedding 模型已缓存（`~/.cache/huggingface/hub/models--sentence-transformers--all-MiniLM-L6-v2/`），RAG 开箱即用。
**决定**：移除 `ENABLE_RAG=false`，让用户享受文档检索能力。
